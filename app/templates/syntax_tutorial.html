2. Mermaid diagrams

Use a fenced block with language mermaid. Great for flowcharts, sequence, and state diagrams (SE behavior models).

Flowchart

Source

```mermaid flowchart LR V[Vision] --> N[Needs] N --> U[Use cases] U --> R[EARS requirements] R --> D[Design] ```

Rendered

flowchart LR
    V[Vision] --> N[Needs]
    N --> U[Use cases]
    U --> R[EARS requirements]
    R --> D[Design]

Sequence diagram

Source

```mermaid sequenceDiagram actor Op as Operator participant AOC participant VCS as Frequentis VCS Op->>AOC: Report track AOC->>VCS: Voice tasking VCS-->>Op: Acknowledge ```

Rendered

sequenceDiagram
    actor Op as Operator
    participant AOC
    participant VCS as Frequentis VCS
    Op->>AOC: Report track
    AOC->>VCS: Voice tasking
    VCS-->>Op: Acknowledge

State diagram

Source

```mermaid stateDiagram-v2 [*] --> NotStarted NotStarted --> CheckedIn: check_in CheckedIn --> CheckedOut: check_out CheckedOut --> CheckedIn: check_in ```

Rendered

stateDiagram-v2
    [*] --> NotStarted
    NotStarted --> CheckedIn: check_in
    CheckedIn --> CheckedOut: check_out
    CheckedOut --> CheckedIn: check_in

3. PlantUML

Use language plantuml. Diagrams render via the PlantUML server (same approach as the registry). Prefer @startuml … @enduml.

Source

```plantuml @startuml skinparam style strictuml actor Operator participant "AOC / C2" as AOC participant TEWA participant VCS Operator -> AOC: Detect / track report AOC -> TEWA: Evaluate threat TEWA --> AOC: Assign recommendation AOC -> VCS: Voice order to effector @enduml ```

Rendered

Requires network access to plantuml.com (or set CISS_PLANTUML_SERVER for a private server).

4. KaTeX mathematics

Inline: $...$ or \(...\). Display: $$...$$, \[...\], or a fenced math / latex block.

Source

Inline: the energy relation $E = mc^2$ is familiar. Display: $$ \sum_{i=1}^{n} i = \frac{n(n+1)}{2} $$ Fenced block: ```math P(A|B) = \frac{P(B|A)\,P(A)}{P(B)} ```

Rendered

Inline: the energy relation $E = mc^2$ is familiar.

Display:

$$\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$$

Fenced block:

\[P(A|B) = \frac{P(B|A)\,P(A)}{P(B)}\]

5. Images

In the content editor, use 🖼 Image or paste from the clipboard. Instructors only. Markdown form:

![Alt text describing the figure](/static/uploads/content/your-file-name.png)
  • Allowed: PNG, JPEG, GIF, WebP, SVG
  • Max size: 5 MB (configurable)
  • Stored under app/static/uploads/content/
