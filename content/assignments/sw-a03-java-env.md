# SW-A03 — Java Tooling & Mini Project

**Weight:** 10% · **Due:** After sw-03-vscode-java · **Module:** sw-03-vscode-java

## Prompt

Prove your **JDK + VS Code + Maven** baseline works: a tiny Java app you can run and debug.

## Deliverables

1. **Environment sheet:** Java version (`java -version`), vendor (OpenJDK/other), Maven version, OS. Note whether you use **JDK 8** or a newer LTS and why for this lab.
2. **Maven project** (or provided starter) with a `main` that prints a structured line (e.g. app name + config value).
3. **Debug evidence:** breakpoint hit — screenshot or short note of variables observed.
4. **Extension list** you installed for Java (from the module recommendations).
5. **Run instructions** in a short README (3–8 lines): open, build, run.

## Quality bar

- Another intern can run your project from the README alone.
- No committed `target/` clutter or IDE secrets.
- You can explain JDK vs JRE in one sentence in the environment sheet.

## Rubric

| Dimension | Max | What we look for |
|-----------|-----|------------------|
| environment | 10 | Reproducible tooling notes |
| runnable | 15 | Project runs; debug shown |
| communication | 5 | README clear |
