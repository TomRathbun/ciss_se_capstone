# A1 — Context & Stakeholders

**Weight:** 10% · **Due:** Week 2 Thursday

## Prompt

Produce a short SE starter pack for **either**:

- SDC Time Tracker (ETAS), or  
- A simple system you know well (must still be a “system” with users + external world)

## Deliverables

1. **Operational need** — 2–4 sentences  
2. **Stakeholder table** — ≥ 4 stakeholders with concerns  
3. **Context diagram** — text sketch or uploaded description of boxes/arrows  
4. **In-scope / out-of-scope** — ≥ 3 each  
5. **Assumptions** — ≥ 2  

## Length

About 1–2 pages equivalent. Clarity over volume.

## Rubric (see catalog)

completeness · boundary_clarity · communication
