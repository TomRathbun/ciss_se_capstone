# NET-FA01 — Path and device-roles sheet

**Time box:** 2 hours. Stop at 2 hours and turn in what you have.
**Due:** Week 1 Wednesday morning, before the Software lecture
**Module:** net-f01-how-built
**Weight:** 7% of this track’s intern-selection score.

## Prompt

Prove you can talk about a network without a vendor CLI.

## Deliverables

1. **Path drawing** (boxes + arrows) from a user PC to a server through at least one switch and one firewall. Caption each hop’s role.
2. **Device-roles table** (switch / router / firewall / host) with one sentence each.
3. **Two failure stories:** “cannot ping gateway” and “HTTPS times out but ping works.” Name the layer you would suspect first and why.
4. **SE sentence:** how this path would show up on a context diagram.

## Quality bar

Vendor-neutral. Path is a path, not a brand list. Layers are not guessed at random.
