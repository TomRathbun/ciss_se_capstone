# A2 — Requirements Pack

**Weight:** 25% · **Due:** Week 4 Thursday (draft feedback Week 3)

## Prompt

Write a requirements baseline for a system scope you define (ETAS subset or other — state the scope).

## Deliverables

1. Scope statement (½ page max)  
2. **8–12 functional requirements** with IDs (`FR-…`) using shall  
3. **≥ 3 NFRs** with IDs (`NFR-…`)  
4. **≥ 5 acceptance criteria** in Given/When/Then, each tracing to an FR ID  
5. List of explicitly **out-of-scope** items  

## Quality bar

If a smart peer cannot test your AC without asking you questions, rewrite it.

## Rubric

testability · shall_quality · coverage · communication
