# ADMIN-A00 — Admin Track Plan & Ops Map

**Weight:** 5% · **Due:** After admin welcome · **Module:** admin-00-welcome

## Prompt

Show how **system administration & integration** supports running software the SW track builds.

## Deliverables

1. **Track plan** (½ page): module order, one access dependency (VPN, VM, IPA, etc.), mitigation.
2. **Ops map:** table linking SW runtime needs (VM, DB, broker, TLS, identity, shares) to **admin modules** that cover them.
3. **Three SE links:** availability, interface (ICD), and verification/evidence in admin work.
4. **Safety rules** you will follow (sudo, production, secrets) — ≥ 5 bullets.

## Quality bar

- Map is concrete (not “admins help software”).
- Safety rules show restraint (least privilege, change windows).

## Rubric

| Dimension | Max | What we look for |
|-----------|-----|------------------|
| completeness | 10 | Plan + map + SE links + safety |
| accuracy | 10 | Correct module ↔ runtime links |
| communication | 5 | Clear for a peer |
