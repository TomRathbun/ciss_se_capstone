# SW-A01 — Git Daily Loop Lab

**Weight:** 10% · **Due:** After sw-01-git · **Module:** sw-01-git

## Prompt

Demonstrate the **daily Git loop** with a tiny public-friendly repo (or class lab repo): branch → commit → push → recover from a simple mistake.

Use branch naming that matches program style when possible: `DR-###-short-slug` (or `lab-###-short-slug` if no DR).

## Deliverables

1. **Repo evidence:** remote URL (GitLab preferred) + branch name.
2. **Command log** (copy/paste or screenshots) of: clone/pull, branch, ≥ 2 commits with useful messages, push, `status` / `log --oneline -5`.
3. **Recovery demo:** undo an **unstaged** change *or* amend a commit message before push — document the exact commands and why they were safe.
4. **Commit message critique:** paste 2 good and 1 bad message (yours or rewritten examples) with one-line reasons.
5. Optional: cite an `FR-…` id in one commit message (even if fictional for this lab).

## Quality bar

- Commits are small and messages explain *why*.
- You never force-push `main` or rewrite shared history.
- Recovery steps are reversible and explained.

## Rubric

| Dimension | Max | What we look for |
|-----------|-----|------------------|
| process | 15 | Full daily loop with evidence |
| recovery | 10 | Safe recovery demonstrated |
| communication | 5 | Log and messages readable |
