# SE-A03 — Use Cases from Needs

**Weight:** 8% · **Due:** Week 3 Thursday · **Module:** se-03 Use Cases from Needs  
**Cadence:** Assigned Monday after the use-case lecture. Continue **your A1 system**. Due Thursday.

## Prompt

Turn **A1 needs** into use cases. Do not skip to EARS yet — that is A2.

If A1 is not finished, use the ETAS or AIC2 teaching examples from the module, and say so at the top.

## Deliverables

1. **Parent recap (short):** paste your vision title + 2 principles, and **two** needs in course grammar (`As` / `we need` / `so that`), each with a vision link.
2. **Use-case index** — at least **4** use cases in a table:

   | UC-ID | Name (verb phrase) | Primary actor | Goal | Related need | Vision principle check |
   |-------|--------------------|---------------|------|--------------|------------------------|
   | UC-… | | | | | |

3. **Full brief for 2 use cases** (not all four). Each brief must include:
   - UC-ID, name, primary actor, goal, precondition
   - Main success scenario (numbered steps)
   - **≥ 2 extensions** (failures / rejects / already-done)
   - Related need(s) + **Vision link**
4. **Rejected UC (one row):** a use case you *considered* that would violate a vision principle — and why you rejected it.
5. **Trace table** (FR column left blank):

   | Vision / principle | Need **derives_from** | Use case **traces_to** | Later FR **allocated_to** |
   |--------------------|----------------------|------------------------|---------------------------|
   | | | | *(blank until A2)* |

## Quality bar

- Names are goals (“Export quarterly package”), not clicks (“Press export”).
- Extensions are where IF/THEN requirements will be born — they are specific, not “error occurs.”
- Every UC still respects a named vision principle.

## Rubric

| Dimension | Max | What we look for |
|-----------|-----|------------------|
| derivation | 15 | UCs clearly traces_to named needs; vision check present |
| completeness | 10 | Index + 2 full briefs + reject + trace table |
| communication | 5 | A peer could write EARS from your extensions |
