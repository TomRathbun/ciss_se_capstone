# SW-A11 — Situational Awareness Client

**Phase:** capstone · **Weight:** 25% of capstone-SW · **Due:** After sw-11 · **Module:** sw-11-prsas-client

## Prompt

Build the **operator picture**: auth, bulk load, live topic, map.

## Deliverables

1. Choice statement: JavaFX **or** web+Java bridge.
2. Auth path (IPA/cert or labelled stub + ADMIN ticket).
3. Bulk load + live apply by `track_id`.
4. Map: symbol, Mode 3/A, vector, trail, CONFLICT styling, filter/zoom.
5. Reconnect behaviour (tested or reasoned with a packet/log).
6. Unclassified screenshot(s).

## Quality bar

- Messaging thread ≠ UI thread.
- Two clients must be *able* to attach (even if you demo one).
- No classified imagery.

## Rubric

| Dimension | Max | What we look for |
|-----------|-----|------------------|
| picture | 15 | Map + labels + conflict visible |
| integration | 10 | Bulk + live + auth story |
| communication | 5 | Screenshot + run notes |
