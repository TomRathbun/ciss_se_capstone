# Weapons & Platforms Context (Lockheed Heritage)

## Purpose

Give interns a **shared public vocabulary** for platforms and systems that appear in mission discussions — using the same Tactical Library spirit as the SDC Time Tracker innovation gallery.

## How to use this module

1. Open the time tracker **Tactical Library** / innovations page when available.  
2. For each item below, say: *mission roles it supports*, not classified employment.  
3. Tie back to planning factors: range, sensors, weapons concept, C2.

## Representative categories

| Category | Example systems (public) | Planning conversation |
|----------|--------------------------|------------------------|
| 5th-gen fighter | F-35 Lightning II | Multi-role, sensor fusion, survivability in contested airspace (conceptually) |
| Air dominance | F-22 Raptor | Air superiority focus |
| Multirole fighter | F-16 Fighting Falcon | Widely fielded multirole workhorse |
| Airlift | C-130J, C-5 | Lift, logistics, special mission variants |
| Maritime patrol | P-3 Orion heritage | ASW / maritime SA concepts |
| Rotary | Black Hawk, CH-53K | Troop lift, heavy lift |
| Munitions / strike | JASSM, LRASM, Hellfire, Javelin | Standoff vs direct attack families (high level) |
| Missile defense | PAC-3, THAAD, Aegis | Different layers of defense — different C2 pictures |
| Space / C2 | GPS III, SBIRS, C2BMC | Timing, warning, battle management |

## Exercise (30 min)

Pick **one air mission type** from the ATO planning module. Choose **two** platforms from the library that could participate (primary + support). Write 6 bullets:

1. Why primary fits the objective  
2. What support platform provides  
3. One fuel/tanker concern  
4. One sensors/SA concern  
5. One comms/datalink concern  
6. One thing you still need to ask an SME  

## Integrity note

Public product pages and museums/history are fine sources. Do **not** hunt classified material. If you do not know, write the **question**, not a guess dressed as fact.
